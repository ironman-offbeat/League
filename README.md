# League

한 사람이 네 챔피언을 지휘하는 모바일 실시간 전술 게임입니다.
자동 전투에 이동, 후퇴, 돌진, 궁극기 타이밍으로 개입합니다.

## 현재 버전 07 · 적 챔피언 AI

네 챔피언의 **스킬 연습장과 한 라인 공성 경기**입니다. 같은 네 챔피언으로 구성된 적 AI 팀과 싸우는 축소 전장입니다. 전체 맵을 갖춘 완성 게임은 아닙니다.

- 네 챔피언 독립 명령·선택 전환, 근접/원거리 공격
- 레넥톤 Q/W·분노·돌진·거대화, 애니 화염·보호막·기절·곰 소환
- 애쉬 공속 강화·일제 사격·둔화·정찰·얼음 화살
- 아무무 붕대·저주·지속 피해·범위 공격·속박
- 수동 돌진, 궁극기 체험, 귀환, 훈련 대상 3개와 재생성
- 카메라 이동, 가로 모바일 화면, 일시정지, 백그라운드 정지
- 전투 회귀 테스트와 Chromium/WebKit 브라우저 검사

연습장의 궁극기는 조작 체험을 위해 1레벨부터 열려 있습니다. 경기 모드에서는 4레벨에 해금됩니다.
반격 버튼으로 고정 훈련 대상의 반격을 켜거나 끌 수 있습니다. 붉은 선은 공격 예고입니다.
피격 시 귀환이 취소되고, 사망하면 6.5초 후 자신의 출발 지점에서 부활합니다.
자동 공격 스킬은 궁극기 1회분 마나를 보존합니다. 연습장은 레벨 1 기준이며, 경기에서는 레벨에 따라 기본 능력치가 증가합니다. 스킬은 고정 순서로 3단계까지 자동 강화됩니다.
정찰은 지역 공개 효과를 지원하지만, 연습장에는 정식 전장의 안개·부쉬가 없습니다.
전체 맵, 정식 시야·부쉬, 장애물 길찾기, 정글, 경기 저장은 후속 개발 범위입니다.
캐릭터와 배경은 코드로 그린 임시 도형이며 외부 게임 이미지·음원을 포함하지 않습니다.

## 한 라인 경기

상단 **한 라인 경기**를 누르고 **전선 집결**로 네 명을 전진시키세요. 각 챔피언의 개별 명령도 계속 사용할 수 있습니다. **전선 보기**는 미니언 위치로 카메라를 옮깁니다.

- 10초에 첫 웨이브, 이후 20초마다 근접 3·원거리 2 출발. 3회마다 공성 미니언 추가.
- 아군은 푸른색, 적은 붉은색. 타워는 미니언을 우선 공격하며 붉은 선으로 발사를 예고합니다.
- 적 타워를 먼저 파괴해야 넥서스를 공격할 수 있습니다. 건물에는 기본 공격만 유효하며, 주변 아군 미니언이 없으면 피해가 25%가 됩니다.
- 넥서스 파괴로 승리·패배·동시 파괴 무승부를 판정합니다. 종료 후 다시 경기하거나 연습장으로 돌아갈 수 있습니다.
- 첫 공성 조작 검증을 위해 양 팀 타워 1개·넥서스 1개인 축소 맵입니다. 내부 타워·억제기·슈퍼 미니언과 최종 10~15분 밸런스는 아직 적용하지 않았습니다.

## 검토 방법

1. 영웅을 지면에 끌어 이동하세요.
2. 붉은 훈련 대상에게 끌어 공격하세요. 도중에 적과 싸우며, 대상이 죽어도 공격을 지정했던 위치까지 이동합니다.
3. 뒤로 끌어 추격이 즉시 취소되는지 확인하세요.
4. 하단 수동 스킬·궁극기를 누르고 지점을 선택하거나 전장으로 끌어 사용하세요.
5. 초상화로 전환해도 기존 명령과 소환수가 유지되는지 확인하세요.
6. 반격을 켜서 피격·보호막·귀환 취소를 시험하세요.
7. 빈 지면을 드래그해 카메라를 움직이고 ◎로 영웅에게 돌아오세요.

불편한 부분은 **기기 / 동작 / 기대 결과 / 실제 결과** 순서로 기록해 주세요.
의견을 남길 때에는 공개 저장소이므로 개인정보를 적지 않아도 됩니다.

## 경기 성장

- 미니언이 죽을 때 350 거리 안의 생존 아군끼리 XP를 나눕니다. 막타 보너스는 없고 최대 레벨 아군은 XP 분배에서 제외합니다.
- 근처 생존 아군이 있으면 미니언 골드를 팀에 한 번 지급합니다. 타워 보상은 거리와 무관하게 팀에 지급합니다.
- 팀 시작 골드 200, 경기 10초부터 초당 2. 우물 상점에서 팀 골드로 장비와 포션을 구매합니다.
- 최대 12레벨. 레벨 증가분만큼 현재 체력·마나도 증가하되 기존에 잃은 양은 유지합니다. 사망·귀환으로 성장과 골드를 잃지 않습니다.
- 상단에 팀 골드, 하단에 선택 챔피언의 레벨·경험치가 표시됩니다.

## 상점과 스킬 성장 (06)

한 라인 경기의 **장비 상점**에서 선택 챔피언의 무기·방어구를 강화합니다. 시작 장비는 T1이며, 골드는 팀 전체가 공유합니다. 우물 또는 사망 대기 중에만 구매할 수 있고 상점을 열어도 경기는 계속됩니다.
포션은 한 개 보유하며 화면 왼쪽 아래 버튼으로 사용합니다. 체력·마나가 가득 차 있으면 소비하지 않습니다. 분노 챔피언은 체력 포션만 구매할 수 있습니다.
일반 스킬은 1~3레벨에 배우고 5~7, 9~11레벨에 강화됩니다. 궁극기는 4/8/12레벨에 습득·강화됩니다. 스킬은 수동 포인트 배분 없이 챔피언별 고정 순서로 성장합니다. 연습장에서는 기존처럼 모두 1단계로 체험할 수 있습니다.


## 적 챔피언 AI (07)

적 4명은 미니언과 전진하며 교전하고, 체력이 낮으면 포션·후퇴·안전한 귀환 후 회복하고 다시 합류합니다. 배운 수동 스킬·궁극기를 같은 자원과 재사용 규칙으로 사용하며, 적 팀의 별도 공유 골드로 장비를 구매합니다. 능력치·소득 보너스는 없습니다.
붉은 테두리와 이름표가 적 챔피언입니다. 처치 시 팀 골드 120, 주변 생존 아군에게 경험치 120+피해자 레벨×20을 나눕니다. 타워 범위 안에서 아군 챔피언을 공격한 적은 미니언보다 우선 표적이 됩니다.
현재 AI 판단은 한 라인 전용이며 최종 난이도·경기 시간 밸런스는 미완성입니다. 다음은 맵 확장 전, 정식 시야·부쉬와 마지막 목격 정보의 통합입니다.
