# League

한 사람이 네 챔피언을 지휘하는 모바일 실시간 전술 게임입니다.
자동 전투에 이동, 후퇴, 돌진, 궁극기 타이밍으로 개입합니다.

## 현재 버전 04 · 한 라인 공성

네 챔피언의 **스킬 연습장과 한 라인 공성 경기**입니다. 완성된 4:4 경기는 아직 아닙니다.

- 네 챔피언 독립 명령·선택 전환, 근접/원거리 공격
- 레넥톤 Q/W·분노·돌진·거대화, 애니 화염·보호막·기절·곰 소환
- 애쉬 공속 강화·일제 사격·둔화·정찰·얼음 화살
- 아무무 붕대·저주·지속 피해·범위 공격·속박
- 수동 돌진, 궁극기 체험, 귀환, 훈련 대상 3개와 재생성
- 카메라 이동, 가로 모바일 화면, 일시정지, 백그라운드 정지
- 전투 회귀 테스트와 Chromium/WebKit 브라우저 검사

이 버전의 궁극기는 조작 체험을 위해 1레벨부터 열려 있습니다.
반격 버튼으로 고정 훈련 대상의 반격을 켜거나 끌 수 있습니다. 붉은 선은 공격 예고입니다.
피격 시 귀환이 취소되고, 사망하면 6.5초 후 자신의 출발 지점에서 부활합니다.
자동 공격 스킬은 궁극기 1회분 마나를 보존합니다. 모든 수치는 레벨 1 기준입니다.
정찰은 지역 공개 효과를 지원하지만, 연습장에는 정식 전장의 안개·부쉬가 없습니다.
적 챔피언과의 4:4, 성장, 장비, 전체 맵, 정글, 경기 저장은 후속 개발 범위입니다.
캐릭터와 배경은 코드로 그린 임시 도형이며 외부 게임 이미지·음원을 포함하지 않습니다.

## 한 라인 경기

상단 **한 라인 경기**를 누르고 **전선 집결**로 네 명을 전진시키세요. 각 챔피언의 개별 명령도 계속 사용할 수 있습니다. **전선 보기**는 미니언 위치로 카메라를 옮깁니다.

- 10초에 첫 웨이브, 이후 20초마다 근접 3·원거리 2 출발. 3회마다 공성 미니언 추가.
- 아군은 푸른색, 적은 붉은색. 타워는 미니언을 우선 공격하며 붉은 선으로 발사를 예고합니다.
- 적 타워를 먼저 파괴해야 넥서스를 공격할 수 있습니다. 건물에는 기본 공격만 유효하며, 주변 아군 미니언이 없으면 피해가 25%가 됩니다.
- 넥서스 파괴로 승리·패배·동시 파괴 무승부를 판정합니다. 종료 후 다시 경기하거나 연습장으로 돌아갈 수 있습니다.
- 첫 공성 조작 검증을 위해 양 팀 타워 1개·넥서스 1개인 축소 맵입니다. 내부 타워·억제기·슈퍼 미니언과 최종 10~15분 밸런스는 아직 적용하지 않았습니다.

## 검토 방법

1. 영웅을 지면에 끌어 이동하세요.
2. 붉은 훈련 대상에게 끌어 공격하세요.
3. 뒤로 끌어 추격이 즉시 취소되는지 확인하세요.
4. 하단 수동 스킬·궁극기를 누르고 지점을 선택하거나 전장으로 끌어 사용하세요.
5. 초상화로 전환해도 기존 명령과 소환수가 유지되는지 확인하세요.
6. 반격을 켜서 피격·보호막·귀환 취소를 시험하세요.
7. 빈 지면을 드래그해 카메라를 움직이고 ◎로 영웅에게 돌아오세요.

불편한 부분은 **기기 / 동작 / 기대 결과 / 실제 결과** 순서로 기록해 주세요.
의견을 남길 때에는 공개 저장소이므로 개인정보를 적지 않아도 됩니다.

## 개발

Node.js 24 기준입니다.

```sh
npm install
npm run dev
```

```sh
npm test
npm run build
npx playwright install chromium webkit
npm run test:browser
```

Phaser 4.2.1 + TypeScript + Vite. 배포 출력 디렉터리는 `dist`입니다.
Vercel에서 이 저장소를 가져오면 `vercel.json` 설정을 사용합니다.
