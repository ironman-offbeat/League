# 개발 단계

현재: 09c-1에서 BattlefieldMatch에 네 챔피언 전투 런타임·역할 배정·팀 경제를 연결했고, 09c-2에서 실제 경기 진입 화면을 Top/Mid/Bottom 3라인 전장으로 전환합니다. 경기 진입 시 전체 맵 오버뷰를 먼저 보여주며, Battlefield 공유 시야·부쉬와 3라인 운영 AI·정글 캠프는 후속 단계입니다.

| 단계 | 범위 | 완료 기준 |
|---|---|---|
| 1 | 레넥톤 조작 연습장 | 모바일 이동·공격·후퇴·돌진을 직접 검토 가능 |
| 2 | 공통 전투 | 피해·회복·보호막·CC·시야 판정 검증 |
| 3 | 챔피언 4명 | 전환 후 기존 명령 유지, 모든 스킬 작동 |
| 4 | 한 라인 경기 | 미니언·타워·넥서스·성장·장비·승패 |
| 5 | 전체 맵 | 3라인·정글·부쉬·정글 자동 순회 |
| 6 | 오브젝트와 AI | 드래곤·바론·동등한 시야의 AI로 4:4 성립 |
| 7 | 모바일 완성 | 저장·재개·튜토리얼·사운드·결과 화면 |
| 8 | 밸런스 | 경기 10~15분, 교전·경제·공성·조작 부담 검증 |

현재 구현은 1단계와 네 챔피언 개별 지휘·공유 표적·근접/원거리 기본 공격 기반입니다.
네 명의 전환 후 기존 명령 유지, 개별 체력·자원·쿨타임·귀환을 지원합니다.
네 챔피언의 레벨 1 스킬과 선택형 고정 표적 반격·사망·부활을 구현했습니다.
정찰 영역 공개와 CC 시간·행동 제한을 지원합니다. 정식 맵 안개·부쉬·충돌 경로·에어본 변위는 후속 범위입니다.
현재 연습장에는 정식 시야 맵·장애물 길찾기·레벨 성장·적 챔피언 AI가 없습니다.
표시된 나무와 바위는 장식입니다. 벽 통과 금지는 실제 충돌 맵 도입 시 검증합니다.
분노·Q/W와 궁극기는 체험 및 공통 전투 로직 검증 범위입니다.

## 04 · 첫 한 라인 경기

4단계 중 미니언·타워·넥서스·승패와 재시작을 구현했습니다. 연습장과 동일한 네 챔피언 전투 코드를 사용합니다.
첫 검증 맵은 각 팀 타워 1개와 넥서스 1개입니다. 미니언은 양 팀이 자동 지휘하며, 적 챔피언은 아직 없습니다.
전선 집결은 명시적인 단체 이동 명령이며, 개별 공격·이동으로 언제든 조정할 수 있습니다.
자동 공성은 호위 미니언이 사라지면 타워 사거리 밖으로 후퇴합니다. 직접 공격은 위험을 감수하고 유지합니다.
다음 구현 우선순위: 스킬 단계 성장·장비 구매 → 적 챔피언 AI → 전체 건물 순서와 맵 확장.

## 검토할 질문

- 손가락으로 영웅과 적을 쉽게 집을 수 있는가?
- 이동 명령이 즉시 먹히고 후퇴 의도가 존중되는가?
- 선택하지 않은 챔피언을 맡길 수 있을 만큼 자동 행동이 예측 가능한가?
- 카메라 이동과 명령 드래그가 헷갈리지 않는가?
- 수동 스킬의 위치 지정과 취소가 쉬운가?
- 가족 검토는 조작감 중심으로 진행하고 그래픽 완성도와 구분한다.

## 배포

Vercel 팀의 새 League 프로젝트에 연결합니다. 기존 유사 이름 프로젝트는 재사용하지 않습니다.
도메인은 추후 연결하며 확인하지 않은 주소를 배포 완료 주소로 안내하지 않습니다.

## 그래픽 교체 기반

사용자 요청에 따라 이미지·스프라이트 시트·아틀라스, 8방향 애니메이션, 캐릭터·미니언·건물·배경·발사체·소환수·스킬 이펙트·아이콘의 등록 지점을 분리했습니다. 실제 아트는 아직 연결하지 않았습니다. 전투 타이밍은 그래픽 프레임과 무관하게 시뮬레이션에서 결정합니다. 리소스 규격과 연결 키는 GRAPHICS.md를 따릅니다.

## 05 · 전진 공격과 경기 성장

공격 명령은 지정 당시 목적지를 저장하고 경로상의 적과 교전합니다. 대상 처치 후에도 그 목적지까지 이동하며 이전 출발 위치로 복귀하지 않습니다. 새 이동 명령은 교전을 중단하고 이동만 수행합니다.

경기 모드에 팀 골드, 근처 생존 아군의 경험치 분배, 1~12레벨 능력치 성장, 레벨별 부활 시간과 4레벨 궁극기 해금을 추가했습니다. 체력·마나·공격력·방어력·마법저항·공속에 반영되며 사망·귀환 후에도 유지됩니다.

현재 골드는 모으기만 가능합니다. 장비 구매와 Q/W/E/R의 2·3단계 수치는 다음 작업입니다. 연습장은 기존 1레벨·궁극기 체험 모드를 유지합니다. 한 라인에 네 명을 모으면 XP가 나뉘므로 최종 경기 길이와 성장 속도는 후속 밸런스 검토가 필요합니다.

## 06 · 우물 상점과 3단계 스킬

팀 골드로 무기·방어구 T1→T2→T3 강화, 체력/마나/혼합 포션 구매·사용, 챔피언별 스킬 자동 습득·3단계 강화와 AD/AP 계산을 연결했다. 상점에서 챔피언을 바꾸어 개별 장비와 능력치를 확인할 수 있다. 경제/장비는 경기 한 판 안에서만 유지하고 새 경기에서 초기화한다.
다음 단계는 적 챔피언 AI다. 전체 3라인·정글 맵, 저장과 PWA 완성은 아직 후속 범위다.


## 07 · 한 라인 적 챔피언 AI

적 네 명의 전진·교전·후퇴·안전 귀환·회복·재합류, 포션과 정상 상점 구매를 구현했다. 양 팀 챔피언은 동일한 전투·장비·경험치·부활 코드를 사용한다. 챔피언 처치 보상과 처치 수 표시, 타워의 아군 챔피언 보호 타깃 전환도 추가했다.
이번 단계는 단일 라인용 결정 규칙이며 갱·정글·오브젝트 판단과 난이도 선택은 포함하지 않는다. 다음 단계는 기존 canSee/정찰 계약을 정식 공유 시야·부쉬와 연결하는 작업이다.


## 08 · 공유 시야와 부쉬 통합

양 팀 챔피언·미니언·타워가 시야를 공유하며 부쉬 은폐, 공격 노출, 애쉬 정찰, 마지막 목격을 경기 판정·AI·렌더링에 연결했다. 숨은 적의 현재 위치·사망·부활을 AI가 직접 읽지 못하도록 마지막 목격 메모리를 분리했고, 타워 공격 준비 중 시야 상실, 논타깃/AoE 충돌, 소환수 은폐·노출까지 같은 규칙으로 보완했다.

## 09a · 3라인 경로와 길찾기 기반

전체 맵으로 한 번에 교체하지 않고 navigation 모듈을 별도 시뮬레이션 계층으로 추가한다. Top/Mid/Bottom은 공통 기지와 개별 라인 노드로 정의하고, 정글·강 연결 노드를 포함한 그래프에서 최단 경로를 계산할 수 있게 한다. 라인 진행도·경로상 좌표·횡방향 오프셋은 polyline API로 계산한다.

기존 한 라인 경기는 `prototype-mid` 경로를 같은 API로 사용한다. 미니언의 건물 접근과 적 AI의 전진·후퇴·타워 접근 제한을 x좌표가 아니라 경로 진행도로 표현해 회귀를 막는다. 이 단계에서는 화면을 3라인으로 바꾸거나 정글 캠프를 생성하지 않는다. 다음 단계에서 실제 3라인 건물·웨이브·역할별 시작 경로를 연결한다.


## 09b · 3라인 경기 시뮬레이션 기반

기존 한 라인 `LaneMatch`는 그대로 유지하고 별도 `BattlefieldMatch`를 추가한다. 팀당 Top/Mid/Bottom의 외곽·내부·억제기와 공유 넥서스를 생성하며, 라인별 보호 순서는 외곽→내부→억제기이고 어느 한 라인의 억제기가 파괴되면 넥서스가 공격 가능해진다.

각 라인은 navigation polyline을 그대로 사용해 양 팀 미니언 웨이브를 이동시킨다. 첫 웨이브 10초, 20초 간격, 근접3+원거리2, 3웨이브마다 공성1 규칙을 3라인 각각에 적용한다. 이동은 raw x좌표가 아니라 라인 진행도로 계산한다.

역할별 시작 위치는 레넥톤 Top, 애니 Mid, 애쉬 Bottom, 아무무 Jungle로 데이터화하고 양 팀 대칭 좌표를 사용한다. 이 단계의 BattlefieldMatch는 아직 플레이 화면·챔피언 전투·AI·정글 캠프에 연결하지 않는다. 다음 단계에서 챔피언 4명과 렌더링을 새 경기 구조에 연결한 뒤 플레이 가능한 3라인 모드로 전환한다.


## 09c-1 · 3라인 챔피언 런타임 연결

`BattlefieldMatch`가 공통 `Combat` 챔피언 4명과 적 4명을 직접 소유한다. 레넥톤 Top, 애니 Mid, 애쉬 Bottom, 아무무 Jungle 역할을 데이터화한다. 실제 경기 시작·귀환·부활은 팀 우물로 통일해 경기 시작 시 상점을 사용할 수 있게 하고, 역할 좌표는 전선 집결과 운영 이동에 사용한다. 경기 성장·팀 골드·상점·미니언/타워 전투·처치 보상은 기존 공통 전투 경로를 재사용한다.

## 09c-2 · 실제 3라인 전장 화면 전환

사용자 경기 진입을 기존 `LaneMatch`가 아니라 `BattlefieldMatch`로 전환한다. ArenaScene에서 실제 navigation polyline을 사용해 Top/Mid/Bottom 3라인, 각 라인의 외곽·내부 타워와 억제기, 공유 넥서스, 3라인 미니언 웨이브를 렌더링한다.

경기 진입 직후에는 1600×1000 전체 전장을 한 번에 확인할 수 있도록 오버뷰 카메라를 사용한다. 챔피언 선택이나 영웅 위치·전선 보기 이후에는 일반 전투 배율로 복귀한다. 전선 집결은 각 챔피언을 역할별 경로로 이동시킨다.

이 단계에서는 Battlefield 공유 시야·부쉬를 아직 이관하지 않았으므로 전장을 모두 공개한다. 기존 `LaneMatch`의 시야·AI와 단위 회귀는 보존하며, 다음 단계에서 공유 시야·부쉬를 Battlefield로 옮긴 뒤 3라인 운영 AI를 연결한다.
