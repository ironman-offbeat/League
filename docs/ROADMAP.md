# 개발 단계

| 단계 | 범위 | 완료 기준 |
|---|---|---|
| 1 | 레넥톤 조작 연습장 | 모바일 이동·공격·후퇴·돌진을 직접 검토 가능 |
| 2 | 공통 전투 | 피해·회복·보호막·CC·시야 판정 검증 |
| 3 | 챔피언 4명 | 전환 후 기존 명령 유지, 모든 스킬 작동 |
| 4 | 한 라인 경기 | 미니언·타워·넥서스·성장·장비·승패 |
| 5 | 전체 맵 | 3라인·정글·부쉬·정글 자동 순회 |
| 6 | 오브젝트와 AI | 드래곤·바론·동등한 시야의 AI로 4:4 성립 |
| 7 | 모바일 완성 | 저장·재개·튜토리얼·사운드·결과 화면 |
| 8 | 밸런스 | 경기 10~15분, 교전·경제·공성·조작 부담 검증 |

현재 구현은 1단계와 네 챔피언 개별 지휘·공유 표적·근접/원거리 기본 공격 기반입니다.
네 명의 전환 후 기존 명령 유지, 개별 체력·자원·쿨타임·귀환을 지원합니다.
네 챔피언의 레벨 1 스킬과 선택형 고정 표적 반격·사망·부활을 구현했습니다.
정찰 영역 공개와 CC 시간·행동 제한을 지원합니다. 정식 맵 안개·부쉬·충돌 경로·에어본 변위는 후속 범위입니다.
현재 연습장에는 정식 시야 맵·장애물 길찾기·레벨 성장·적 챔피언 AI가 없습니다.
표시된 나무와 바위는 장식입니다. 벽 통과 금지는 실제 충돌 맵 도입 시 검증합니다.
분노·Q/W와 궁극기는 체험 및 공통 전투 로직 검증 범위입니다.

## 04 · 첫 한 라인 경기

4단계 중 미니언·타워·넥서스·승패와 재시작을 구현했습니다. 연습장과 동일한 네 챔피언 전투 코드를 사용합니다.
첫 검증 맵은 각 팀 타워 1개와 넥서스 1개입니다. 미니언은 양 팀이 자동 지휘하며, 적 챔피언은 아직 없습니다.
전선 집결은 명시적인 단체 이동 명령이며, 개별 공격·이동으로 언제든 조정할 수 있습니다.
자동 공성은 호위 미니언이 사라지면 타워 사거리 밖으로 후퇴합니다. 직접 공격은 위험을 감수하고 유지합니다.
다음 구현 우선순위: 스킬 단계 성장·장비 구매 → 적 챔피언 AI → 전체 건물 순서와 맵 확장.

## 검토할 질문

- 손가락으로 영웅과 적을 쉽게 집을 수 있는가?
- 이동 명령이 즉시 먹히고 후퇴 의도가 존중되는가?
- 선택하지 않은 챔피언을 맡길 수 있을 만큼 자동 행동이 예측 가능한가?
- 카메라 이동과 명령 드래그가 헷갈리지 않는가?
- 수동 스킬의 위치 지정과 취소가 쉬운가?
- 가족 검토는 조작감 중심으로 진행하고 그래픽 완성도와 구분한다.

## 배포

Vercel 팀의 새 League 프로젝트에 연결합니다. 기존 유사 이름 프로젝트는 재사용하지 않습니다.
도메인은 추후 연결하며 확인하지 않은 주소를 배포 완료 주소로 안내하지 않습니다.

## 그래픽 교체 기반

사용자 요청에 따라 이미지·스프라이트 시트·아틀라스, 8방향 애니메이션, 캐릭터·미니언·건물·배경·발사체·소환수·스킬 이펙트·아이콘의 등록 지점을 분리했습니다. 실제 아트는 아직 연결하지 않았습니다. 전투 타이밍은 그래픽 프레임과 무관하게 시뮬레이션에서 결정합니다. 리소스 규격과 연결 키는 GRAPHICS.md를 따릅니다.

## 05 · 전진 공격과 경기 성장

공격 명령은 지정 당시 목적지를 저장하고 경로상의 적과 교전합니다. 대상 처치 후에도 그 목적지까지 이동하며 이전 출발 위치로 복귀하지 않습니다. 새 이동 명령은 교전을 중단하고 이동만 수행합니다.

경기 모드에 팀 골드, 근처 생존 아군의 경험치 분배, 1~12레벨 능력치 성장, 레벨별 부활 시간과 4레벨 궁극기 해금을 추가했습니다. 체력·마나·공격력·방어력·마법저항·공속에 반영되며 사망·귀환 후에도 유지됩니다.

현재 골드는 모으기만 가능합니다. 장비 구매와 Q/W/E/R의 2·3단계 수치는 다음 작업입니다. 연습장은 기존 1레벨·궁극기 체험 모드를 유지합니다. 한 라인에 네 명을 모으면 XP가 나뉘므로 최종 경기 길이와 성장 속도는 후속 밸런스 검토가 필요합니다.
