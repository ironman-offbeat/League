# League 게임 기획 v0.1

2026-10-02 대화와 Mobile_MOBA_Game_Design_Handoff 문서를 기준으로 정리합니다.
기본 방향은 합의 사항이며 상세 수치는 첫 플레이 검증용 제안값입니다.
현재 코드 구현 범위와 목표 게임 전체 기획은 구분합니다.

## 1 게임 방향

한 명이 탑·미드·바텀·정글 4명을 지휘하는 4:4 싱글 플레이 모바일 전술 게임.
기본 전투는 자동, 이동·후퇴·중요 스킬·소모품·귀환·오브젝트 판단은 수동.
목표 경기 10~15분, 적 넥서스 파괴로 승리. 동시 파괴는 무승부.
첫 팀은 레넥톤·애니·애쉬·아무무, 적 팀도 동일 조합.
모바일 가로 웹/PWA를 목표로 하며 계정 성장·가챠·멀티플레이는 초기 제외.

## 2 조작과 명령

영웅 터치 선택, 영웅→지면 드래그 이동, 영웅→적 드래그 직접 공격.
빈 지면 드래그 카메라 이동, 초상화 선택과 카메라 복귀.
수동 스킬은 버튼에서 전장 드래그 또는 버튼 선택 후 지점 지정.
한 번에 한 명에게 명령하지만 나머지는 기존 명령 지속.

이동 명령은 자동 공격보다 우선하며 공격 준비 동작을 취소한다.
이미 발생한 피해·발사된 투사체는 취소하지 않는다. 공격 쿨타임은 초기화하지 않는다.
마지막 이동 또는 공격 지정 지점이 새 활동 기준점이다. 라인에서는 진행도, 정글·강에서는 반경 3단위 기준.
2026-10-05 변경: 직접 공격은 이동과 공격을 합친 명령이다. 명령 당시 지정한 위치를 목적지로 고정하고, 경로상 사거리 안의 적과 교전한다. 지정 대상이 사거리 안에 있으면 그 대상을 우선한다.
지정 대상 추격은 기존 전진 한계를 무시한다. 대상이 죽거나 제거되면 출발 위치가 아닌 저장된 공격 목적지까지 전진하며 교전한다. 대상이 이동한 뒤 죽어도 목적지는 바뀌지 않는다.
시야 상실 시 마지막 목격 위치까지만 추적한 뒤 저장된 공격 목적지로 진행한다. 보이지 않는 대상의 현재 위치는 사용하지 않는다. 부활한 대상은 새로운 개체로 취급한다.
새 이동 명령은 추격과 전진 공격을 취소하고 이동만 수행한다. 돌진·귀환도 기존 공격 목적지를 해제한다.
자동 공격 우선순위: 직접 대상 → 자신/근처 아군 공격 중인 챔피언 → 현재 대상 → 미니언 → 건물.
중립 몬스터는 직접 지정 또는 정글 순회 중에만 공격한다.
자동 공성은 아군 미니언이 타워에 먼저 진입한 경우만 허용, 전멸 시 후퇴.

## 3 전투와 성장

피해 = 원래 피해 × 100 / (100 + 방어). 물리/마법 각각 방어력/마법저항 적용.
치명타·관통·음수 방어·고정 피해는 초기 제외.
1~12레벨, Q/W/E/R 각 3단계. R은 4/8/12레벨, 나머지는 개별 고정 순서.
일반 스킬 2개 자동, 1개 수동, 궁극기 수동. 패시브는 처음부터 적용.
마나형 자동 공격 스킬은 궁극기 습득 후 궁극기 1회분 마나 보존.
방어 스킬·수동 스킬은 보존 제한 예외. 이동 중 공격용 자동 스킬 중단.
체력 초당 최대치 0.3%, 마나 초당 최대치 0.8% 자연 회복.
레벨당 공격속도는 기본값의 2% 가산.

## 5 시야와 CC
